# 招标文件提取指南

阶段 2（结构定位）开始前必须加载本文件。内容：六大区域的提取要点、强制性用词判定、高频易漏点清单。

## 一、六大区域提取要点

### A. 资格要求区域

常见位置：第一章"投标人须知"或"投标人资格要求"、"供应商资格要求"、须知前附表（表格形式，极易漏，逐格看）。

要点：
- 资格要求通常以"（一）（二）（三）"编号列出，每一条对应至少一项材料：资质证书、许可证、财务报告、社保、纳税、信用记录、业绩等。
- 注意"法人或其他组织""具有良好的商业信誉"这类表述背后的具体材料要求：商业信誉通常落在"信用中国/政府采购严重违法失信名单查询记录截图"上，但**只有原文明确要求提供截图或声明时才进清单**，原文没写就不要添加。

### B. 评审办法区域

常见位置：第二章"评标办法"、评标办法前附表、评分细则表。

要点：
- 分三块看：**资格性审查**（不通过即无效）、**符合性审查**（不通过即无效）、**评分项**（影响得分）。
- 资格性/符合性审查表里每一行的审查内容几乎都对应一份材料，逐行提取。
- 评分细则逐条提取：每条打分点反问"评委凭什么给这一分"，证明材料即答案。常见：类似业绩合同+验收证明、荣誉证书、认证证书、人员职称/证书、方案编写质量（这类通常不是"提供的材料"而是投标文件本身的内容，注意区分）。
- 注意分值与限定条件：如"每提供一个 XX 项目业绩得 2 分，最多 6 分"——限定条件（合同时间范围、金额要求、证明形式）必须原样记录。

### C. 投标文件组成区域

常见位置："投标文件组成/应包括下列内容""第X章 投标文件格式"。

要点：
- 这是最容易被忽视但最完整的一节：格式章节里每份格式文件（函、表、声明）都隐含"需要提供"的要求。
- 逐个格式标题扫描：投标函、开标一览表、分项报价表、法定代表人身份证明、授权委托书、资格声明函、各类声明函（中小企业声明函、无重大违法声明函等）。
- 每个格式文件对应清单一条，注明"按第X章格式填写"。

### D. 否决/无效条款区域

常见位置：投标人须知中"投标无效情形""否决投标的情形"、评标办法中"无效投标条款"。

要点：
- 逐条精读，很多硬性材料要求只在这里出现，例如："未按规定缴纳投标保证金的，投标无效"→ 需要保证金缴纳凭证；"未按格式提供中小企业声明函的视同..."。
- 特别注意"未提供XX""未加盖公章""未经签字"等否定式表述，它们定义了清单中材料的**形式硬指标**（盖章、签字、份数）。

### E. 技术要求区域

常见位置：第三章"采购需求/技术规范/货物需求清单"。

要点：
- 逐个参数/条目看是否要求附证明：检测报告、产品彩页、说明书、授权书（制造商授权）、3C 认证等。
- 货物类："★"号参数或"▲"号参数通常强制要求提供证明材料（检测报告等），**带星号条款逐条核对**。
- 注意"提供产品彩页并标注"这类特殊形式要求。

### F. 商务条款区域

常见位置：交货期/工期/质保/付款/售后条款。

要点：
- 需要响应证明的提取（如质保承诺函、服务承诺书），纯客观条件（如"交货期 30 天"）本身不是材料，但若要求"承诺函"则进清单。
- 注意"其他要求""特别说明"小节，常藏补充材料要求。

## 二、强制性用词判定表

| 原文用词 | 强制级别判定 |
|---|---|
| 必须、须、应、应当、要 | 强制 |
| 否则投标无效/否决/按无效处理/不予受理/拒绝 | 强制（该条对应材料形式要求从严） |
| 至少/不少于 X 份、正本/副本 | 强制 + 形式要求 |
| 提供…得 X 分、酌情加分 | 评分 |
| 如有/可以提供/建议/宜 | 待确认（提问，不归类） |
| 招标人负责/招标人组织/由招标代理 | 非投标人材料，不进清单 |
| 未提供/未加盖/未签署（否定式） | 强制（反向定义材料及其形式） |

## 三、高频易漏点清单（阶段 4 查漏用）

以下材料经常不出现在"资格要求"里，而是散落在格式章节、无效条款、评分细则中，逐项对照确认：

- [ ] 法定代表人身份证明 / 授权委托书（及授权人身份证复印件）
- [ ] 投标保证金缴纳凭证 / 保函
- [ ] 信用记录查询截图（信用中国、政府采购网）或信用承诺书
- [ ] 中小企业声明函 / 残疾人福利单位声明函 / 监狱企业证明
- [ ] 无重大违法记录声明函
- [ ] 投标人资格声明函 / 符合性声明
- [ ] 开标一览表 / 分项报价明细表（按格式）
- [ ] 业绩合同 + 中标通知书 / 验收证明（注意时间范围限定词）
- [ ] 制造商授权书 / 质保承诺函
- [ ] 检测报告（对应★/▲参数）
- [ ] 人员证书、社保证明（对应人员评分项）
- [ ] 审计报告 / 纳税凭证 / 社保缴纳凭证（注意"近X年"限定）
- [ ] 电子签章 / 电子投标文件 / UKey 要求（电子标中）
- [ ] 递交份数与密封要求（正本X份、副本X份、电子版X份）
- [ ] 廉政承诺书 / 履约承诺函 / 其他专项承诺函

核对方法：以上每项都问一遍——"本项目的招标文件是否要求提供？"有原文依据的保留并标注出处，没有的跳过。**这张清单本身绝不作为直接进入清单的依据，仅用于查漏。**
